# Sales Reminder System

A robust, scalable Google Apps Script project for automating sales reminders via Google Sheets.

## Overview
This system serves as an automated CRM assistant within Google Sheets. It tracks upcoming sales follow-ups, contract renewals, and customer touchpoints, dispatching notifications automatically via email.

## Setup & Deployment
This project is structured to be deployed using [`clasp`](https://github.com/google/clasp).

1. Clone or sync the existing script using `clasp clone <SCRIPT_ID>`
2. Install dependencies (if any) and push changes using `clasp push`
3. Configure the Spreadsheet ID and necessary Script Properties in the GAS Editor.
